# RachaAí

Protótipo de baixa fidelidade desenvolvido para a disciplina de Interação Humano Computador e UX.

O aplicativo **RachaAí** foi criado com o objetivo de facilitar a divisão de despesas entre pessoas que compartilham gastos em casas, apartamentos, viagens ou repúblicas.

---

##  Aluna

* esquecimentos de pagamento
* cálculos incorretos
* falta de transparência
* cobranças desconfortáveis

O aplicativo permite que usuários organizem despesas coletivas de forma simples, rápida e visual.

---

##  Persona

### Público-alvo

* estudantes universitários
* moradores de república
* amigos que dividem apartamento
* grupos de viagem

### Necessidades

* controlar gastos compartilhados
* acompanhar pagamentos
* visualizar quem deve
* receber lembretes automáticos

---

##  Funcionalidades do Protótipo

### Dashboard de Grupos

Visualização dos grupos ativos e saldo geral.

### Adicionar Gasto

Cadastro de despesas com:

* descrição
* categoria
* valor
* participantes
* divisão de valores

### Scanner de Nota Fiscal

Interface simples para captura de notas fiscais.

### Extrato de Dívidas

Tela com:

* quem deve
* valores pendentes
* ações de cobrança e pagamento

### Notificações

Lembretes automáticos de pagamentos pendentes.

### Perfil do Usuário

Informações básicas do participante.

---

##  Heurística de Nielsen Priorizada

### Visibilidade do Status do Sistema

O protótipo foi desenvolvido priorizando feedback visual claro ao usuário, permitindo acompanhar:

* pagamentos realizados
* valores pendentes
* cobranças
* alterações no sistema

Essa abordagem aumenta a sensação de segurança e transparência durante o uso.

---

##  Fluxo de Tarefa

### Dividir uma conta de luz entre 3 pessoas

1. Acessar o grupo da casa
2. Selecionar “Adicionar gasto”
3. Inserir descrição da conta
4. Informar o valor
5. Selecionar os participantes
6. Confirmar o cadastro
7. O sistema realiza a divisão automaticamente
8. Os participantes recebem a cobrança

---

##  Decisões de UX

O protótipo utiliza:

* interface simples
* navegação objetiva
* foco nas informações financeiras
* ações rápidas e acessíveis
* organização visual limpa

O objetivo é reduzir ansiedade e evitar conflitos relacionados a dinheiro.
